# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

`dev-tools` is a multi-tool monorepo. Container-level guidance (layout, where tools live, root commands) is in [AGENTS.md](./AGENTS.md) — read it first.

**Before working on a specific tool, read that tool's own docs**, e.g. for How Does This Work:
[`src/how-does-this-work/AGENTS.md`](./src/how-does-this-work/AGENTS.md) (and its `CLAUDE.md`). Each tool carries its own architecture, conventions, and current state.
