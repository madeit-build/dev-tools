# Architecture decision records

One file per decision, named `YYYY-MM-DD-<topic>.md`, matching `docs/specs/`.

**An accepted ADR is immutable.** A changed decision gets a new ADR that
supersedes the old one. The old one gains a `Superseded by` line and nothing
else about it is edited.

An ADR is for a decision with alternatives that constrains work not yet
written. A design scoped to one tool belongs in `docs/specs/`.

State the measurement, not the intuition.
